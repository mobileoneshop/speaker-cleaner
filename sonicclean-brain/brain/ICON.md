# ICON — SonicClean

## Concept
A speaker cone emitting clean concentric sound waves, on a deep-navy rounded
tile with the cyan→violet accent gradient. Minimal, legible at 48dp.

## Specs
- Foreground: white/cyan speaker glyph + 3 wave arcs, centered, 60% of canvas.
- Background: `#0B0F1A` → `#141B2E` subtle vertical gradient (adaptive-icon bg).
- No text on the icon. No tiny details — must read at 48×48dp.
- Deliverables: `mipmap-*/ic_launcher` PNGs (48/72/96/144/192) + adaptive-icon
  XML (foreground/background layers) + 512×512 store listing PNG.

## Anti-vibe-code rule
No default Android robot, no clipart speaker, no rainbow gradients. One accent
gradient only. Final art needs normathi's approval before M14.
